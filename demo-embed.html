📦 Hướng Dẫn Nhúng Mascot Kito Vào Website

Nhẹ <15KB, Zero-dependency, Shadow DOM siêu mượt không làm ảnh hưởng CSS trang web chính!

1️⃣ Nhúng 1 Dòng Code HTML

Thêm thẻ <script> vào trước thẻ đóng </body> của website bạn:

<script src="https://your-domain.com/mascot-widget.js"></script>
<script>
  const mascot = KitoMascot.init({
    name: 'Kito',
    color: '#6366f1',
    mode: 'roam'
  });
</script>

2️⃣ Khai Báo Gợi Ý Bằng HTML Attribute

Gắn thuộc tính data-mascot-hint vào bất kỳ button hoặc link nào để Mascot tự động bay đến chỉ dẫn khi rê chuột:

<button data-mascot-hint="Mua ngay giảm 20%!">
  🛒 Mua Hàng
</button>
